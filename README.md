# 异常归并台 · 半导体洁净室巡检

把“同一房间、同一设备、同一种缺陷被拆成多张单”的重复上报归并为一个事件的看板。

## 归并规则

- **归并键 = 房间 + 设备 + 缺陷代码（相同三项）**
- 整改单**关闭前**：相同三项的新上报自动**并入同一事件**，待整改仍按 1 个事件计数；
  每次上报（发生时刻、原始现象）逐条保留，可展开查看；
  整改期限锚定**首报发生时刻 + 缺陷代码 SLA**，续报不顺延。
- 整改单**关闭后**：再报同代码（同三项）**另开新事件**；旧事件的关闭时间与期限冻结不动。
- 待整改统计**按事件计数**，同时单独统计逾期事件、已关闭事件与累计上报次数。

## 录入字段

房间编号、设备、缺陷代码（字典选择）、发生时刻、原始现象。
缺陷代码资料（代码、名称、严重度、SLA 小时）集中维护在规则层。

## 代码分层（资料规则 / 本机存储 / 页面分开）

| 文件 | 职责 | 依赖 |
| --- | --- | --- |
| `src/rules.ts` | 缺陷代码字典、归并键、上报归并、关闭、统计、时间格式化（纯函数） | 无 |
| `src/storage.ts` | localStorage 读写、版本标记、损坏回退 | 仅浏览器 localStorage |
| `src/App.tsx` + `src/styles.css` | 录入表单、待整改/已关闭看板、事件卡展开、关闭整改单 | React（脚手架原有） |

`src/react-env.d.ts` 是本地环境声明：脚手架未声明 `@types/react`，
为遵守“不加依赖”，仅以声明文件描述本项目用到的 React API 形状，不安装任何 npm 包。

## 本机存储

数据保存在浏览器 `localStorage`（键 `cleanroom-merge-desk:v1`），
不访问网络、不发送服务器，关闭页面/重开浏览器后仍在；清除浏览器站点数据即清空。
存储损坏或版本不符时安全回退为空看板。

## 本地运行

```bash
npm install
npm run dev      # 开发，端口 5109
npm run build    # 类型检查 + 构建
```

未新增任何第三方依赖（沿用脚手架的 React + Vite + TypeScript）。
